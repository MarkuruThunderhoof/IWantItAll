## I Want It All
This is yet another addon to rotate all your resource tracking abilities (TWoW included) with a single button.
Type `/iwia` to display the list of available commands and tracking abilities.
Type `/iwia next` to switch to the next enabled tracking ability, or bind it in the "Key Bindings" menu.
### Supported Tracking Abilities
- ![](https://wow.zamimg.com/images/wow/icons/small/inv_misc_flower_02.jpg) **Find Herbs** &rarr; `/iwia herbs on|off`
- ![](https://wow.zamimg.com/images/wow/icons/small/spell_nature_earthquake.jpg) **Find Minerals** &rarr; `/iwia ores on|off`
- ![](https://wow.zamimg.com/images/wow/icons/small/inv_tradeskillitem_03.jpg) **Find Trees** &rarr; `/iwia trees on|off`
- ![](https://wow.zamimg.com/images/wow/icons/small/inv_misc_fish_02.jpg) **Find Fish** &rarr; `/iwia fish on|off`
- ![](https://wow.zamimg.com/images/wow/icons/small/racial_dwarf_findtreasure.jpg) **Find Treasure** &rarr; `/iwia chests on|off`
